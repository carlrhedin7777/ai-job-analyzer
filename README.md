# AI Job Analyzer

Ett Python-projekt som analyserar jobbannonser inom AI/IT och identifierar vilka kompetenser, verktyg och certifikat som efterfrågas.

**Kurs:** Utveckling med Python – grundnivå  
**Roll:** AI Engineer  
**Status:** Under utveckling

# Funktioner (planerade)

 Läsa jobbannonser från JSON/CSV
 Hämta data från ett publikt API
 Analysera text för att hitta kompetenser
 Matcha användarens kompetenser mot annonsen
 Spara analysresultat
